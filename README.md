# AccessMetro SP

Site de acessibilidade no metrô e nos trens de São Paulo: status das linhas, recursos de acessibilidade de cada estação (elevador, banheiro, rampa, piso tátil), mapa e relatos de problemas feitos pelos próprios usuários.

Projeto da turma 2ADM2 do Senac Nações Unidas. Entrega: 28/11/2026.

## Onde está cada coisa
- **Código do site:** `40-produto/app/` (Vite + React + TypeScript)
- **Onde estamos agora:** `20-direcao/PAINEL.md`
- **Mapa de todas as pastas:** `MAPA.md`
- **Regras para IAs que trabalham no projeto:** `AGENTS.md`

Este repositório é organizado como um "palácio da memória": cada assunto mora numa pasta numerada fixa, e as decisões e erros ficam registrados em `80-memoria/` para ninguém precisar rediscutir o que já foi resolvido.
